# GitHub.dev Web Editor Documentation

## What is this application?

The **github.dev web-based editor** is a lightweight, browser-based code editing experience that runs entirely in your web browser. This application allows you to:

- Navigate files and source code repositories from GitHub
- Edit code with full Visual Studio Code functionality
- Make and commit code changes directly from the browser
- Work with multiple files simultaneously

## How to Access GitHub.dev

There are **two simple ways** to access the VS Code environment in your browser:

### Method 1: The "." Key
* Navigate to any GitHub repository or pull request
* Press the **"."** (period) key on your keyboard
* You'll be instantly redirected to the github.dev editor

### Method 2: URL Modification
* Replace `.com` with `.dev` in any GitHub URL
* **Example**: `https://github.com/github/dev` becomes `https://github.dev/github/dev`

- **Platform**: Web-based (browser-only)
- **Engine**: Visual Studio Code for the Web
- **Requirements**: Modern web browser with internet connection
- **Integration**: Full GitHub ecosystem integration
