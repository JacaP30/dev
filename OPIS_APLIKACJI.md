# Opis Aplikacji - Co robi ta aplikacja?

## Czym jest ta aplikacja?

To repozytorium zawiera dokumentację dotyczącą **GitHub.dev** - web-owego edytora kodu GitHub, który działa w całości w przeglądarce internetowej.

## Główne funkcje i możliwości:

### 1. **Edytor kodu w przeglądarce**
- Lekki edytor działający w 100% w przeglądarce
- Nie wymaga instalacji żadnego oprogramowania
- Bazuje na Visual Studio Code

### 2. **Nawigacja po plikach i repozytoriach**
- Przeglądanie plików w repozytoriach GitHub
- Nawigacja po kodzie źródłowym
- Dostęp do wszystkich plików w repozytorium

### 3. **Edycja i zatwierdzanie zmian**
- Możliwość edycji wielu plików jednocześnie
- Zatwierdzanie (commit) zmian bezpośrednio z przeglądarki
- Wszystkie zaawansowane funkcje edytora VS Code

## Jak używać GitHub.dev?

Istnieją **dwa sposoby** dostępu do edytora:

### Metoda 1: Klawisz "."
- Znajdź się w dowolnym repozytorium GitHub lub pull request
- Naciśnij klawisz **"."** (kropka)
- Automatycznie zostaniesz przeniesiony do edytora

### Metoda 2: Zmiana URL
- W adresie URL zamień `.com` na `.dev`
- Przykład: `https://github.com/github/dev` → `https://github.dev/github/dev`

## Dlaczego warto używać?

### ✅ **Zalety:**
- **Szybkość** - natychmiastowy dostęp do edytora
- **Wygoda** - nie trzeba klonować repozytorium lokalnie
- **Funkcjonalność** - pełne możliwości VS Code w przeglądarce
- **Efektywność** - idealne do szybkich zmian i poprawek
- **Dostępność** - działa na każdym urządzeniu z przeglądarką

### 🎯 **Najlepsze zastosowania:**
- Szybkie poprawki w kodzie
- Edycja dokumentacji
- Przeglądanie kodu
- Małe zmiany w projektach
- Praca na urządzeniach bez zainstalowanego IDE

## Techniczne szczegóły:

- **Platforma**: Web-based (przeglądarka)
- **Bazuje na**: Visual Studio Code
- **Wymagania**: Tylko przeglądarka internetowa
- **Dostępność**: 24/7 przez GitHub
- **Integracja**: Pełna z ekosystemem GitHub

## Status repozytorium:

To repozytorium służy **wyłącznie jako dokumentacja** i nie zawiera kodu aplikacji. GitHub.dev jest usługą świadczoną bezpośrednio przez GitHub.
